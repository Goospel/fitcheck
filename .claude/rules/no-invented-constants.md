# ⛔ 이 경로에서 숫자를 지어내지 않는다

지금 건드리는 파일은 **확정 상수를 쓰는 자리**다. 그럴듯한 숫자를 채워 넣는 것이 이 프로젝트에서 가장 비싼 실수다.

## 미확정 — 채우지 말 것

**지금은 비어 있다.** Q1~Q7 이 전부 종결됐다 (2026-08-20).

⚠️ **비었다는 것이 「아무 숫자나 써도 된다」는 뜻이 아니다.** 새 상수가 필요해지면 그 순간 이 표가 다시 채워져야 한다 — **구현을 멈추고 사용자에게 묻는다.** 아래 「이미 확정된 것」에 없는 숫자를 코드에 처음 쓰는 순간이 그 시점이다.

✅ **A4 추정 계수는 풀렸다** (2026-08-20 · Q3 종결) — 사이즈코리아 8차 조사 앵커 + 스케일 법칙. 값은 `fit/estimate.py` 의 `ANCHORS` 에 있고 **출처 없이 고치지 않는다.**

✅ **기장 5단계 경계는 풀렸다** (2026-08-20 · Q1 종결) — 같은 조사의 랜드마크 높이다. 값은 `fit/length.py` 의 `LANDMARKS` 에 있고 **출처 없이 고치지 않는다.**

✅ **드롭숄더 경계는 풀렸다** (2026-08-20 · Q4 종결, 김정빈) — PRD 6.2.4 예시값 `shoulder_diff >= 4.0cm`. 값은 `images/prompt.py` 의 `SHOULDER_DROP_THRESHOLD` 에 있다.

✅ **소매 밴드 폭은 풀렸다** (2026-08-20 · Q2 종결) — **±2cm 대칭.** 값은 `fit/length.py` 의 `SLEEVE_BAND` 에 있다. ⚠️ 위 셋과 달리 **인체 데이터가 아니라 합의값**이다 — 「차이 0 = 손목」만 조사가 답한다. 고칠 땐 출처가 아니라 **합의**가 필요하다.

이 중 하나가 필요해지면 **구현을 멈추고 `docs/open-questions.md` 를 읽은 뒤 사용자에게 묻는다.** 임시값을 넣고 진행하지 않는다 — 리포트·이미지 프롬프트·사이즈 비교 화면이 한꺼번에 어긋난다.

## 이미 확정된 것은 import 한다

핏 등급 문구 5종은 `fit/grade.py` 에 있다. **문자열을 새로 타이핑하지 않는다.**

```python
from fit.grade import GRADE_ORDER, PREFERRED_GRADES
# GRADE_ORDER    = ("너무 작음","슬림핏","레귤러핏","세미오버핏","오버핏")
# PREFERRED_GRADES = 선호 핏으로 고를 수 있는 4개 (「너무 작음」 제외)
```

D3(프롬프트 변환)·A5(리포트 조립)·프론트 응답이 전부 같은 문자열을 봐야 한다. 한 곳에서 오타가 나면 조용히 갈라진다.
